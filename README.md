# Homebrew Tap

Homebrew formulae maintained by TULIP Lab.

## SpaceWright

Install SpaceWright with:

```sh
brew install tulip-lab/tap/spacewright
```

Upgrade to the latest release with:

```sh
brew update
brew upgrade spacewright
```

The formula is generated from immutable SpaceWright release artifacts. Changes
are validated on Apple Silicon and Intel macOS runners.
